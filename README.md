# gsia-crypto-academy
GSIA Crypto Academy – Plateforme éducative africaine dédiée à l’apprentissage des cryptomonnaies, à la découverte de la blockchain, au suivi des marchés et à la simulation d’investissement sans argent réel. Application Web PWA installable sur Android, avec intégration communautaire Telegram.
